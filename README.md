## Aim: 
To understand the fundamentals of UI and UX design, differentiate between them using real-world case studies, study the relationship between UI and UX, and explore various UI/UX design tools.

## Algorithm:
Step 1: Study the Fundamentals of UI and UX Learn the meaning of User Interface (UI) and User Experience (UX). Understand the principles of usability, accessibility, consistency, and user-centered design. Analyze how users interact with websites and mobile applications. 

Step 2: Differentiate Between UI and UX Using Case Studies Select popular applications such as: Instagram Spotify Amazon Observe their interface design, navigation, colors, typography, and usability. Compare UI elements and UX experience of each application. 

Step 3: Illustrate the Relationship Between UI and UX Create simple sketches or wireframes. Design interface components like buttons, menus, and icons. Test how design decisions affect user experience. Identify how good UI improves UX satisfaction. 

Step 4: Demonstrate UI/UX Design Tools Explore design tools such as: Figma Adobe XD Canva Sketch Create basic wireframes and prototypes. Add colors, typography, and layouts. Preview and test the prototype.
